Rekordbox Last
Played Analysis Tool

Rekordbox records play history but won't let you filter by it. I decrypted a copy of its database,
worked out when each track was last played and imported the results back as playlists.

The Problem

Rekordbox has no "Last Played" field and no smart playlists based on play history. Plays are recorded, but only in auto-generated History playlists, which are left out of XML exports and can't be used as filters. With a library of several thousand tracks, that makes it impossible to find music I haven't played for months or years, which is useful both for clearing out the library and for rediscovering forgotten tracks.

The Investigation

I knew the data existed. The question was how to read it. I used ChatGPT, Gemini and Claude to work through the options, and each got part of the way:

  • ChatGPT identified the Rekordbox database as the right source and outlined a workable pipeline, but missed that the database is encrypted.
  • Gemini identified the SQLCipher encryption, but wrongly said the key was unique to each machine, which would have been a dead end.
  • Claude identified that Pioneer uses a single hardcoded SQLCipher key across all Rekordbox installations, which the developer community has published.

Several confident answers turned out to be wrong, so I checked each claim before building on it.

What I Built

To avoid any risk to my library, the tool never writes to the live database. It reads a decrypted copy and uses Rekordbox's own XML import to bring in the results.

The pipeline:

  1. Export rekordbox.xml from Rekordbox to capture current track IDs
  2. Decrypt a read-only copy of master.db with the published SQLCipher key
  3. Use SQL to find the last played date for each track
  4. Sort tracks into five playlists by time since last played: last 12 months, 12–24, 24–36, 36–48 and 48+ months
  5. Add the playlists to rekordbox.xml, matching tracks by ID
  6. Reload the XML in Rekordbox and import the playlists
  7. Delete the decrypted copy automatically

It all runs from a single macOS Shortcut, with dialogs that check dependencies, warn if the XML export is out of date and confirm the encryption key works.

SEO Reporting Pipeline

A production ETL pipeline for one of the world's leading airlines and hospitality brands,
built as a freelancer for the performance marketing agency Herd.
It moved reporting to a new tracking platform without losing years of historical data,
and covers 15+ brand websites across 13 international markets.

The Challenge

Herd needed to move from a legacy ranking tool to a new platform while keeping years of historical data. The reporting set-up had two problems:

  • Slow, bug-prone reports - all calculations and filtering ran inside Looker Studio.
  • Hard to scale - each client had its own codebase for building reporting tables, which made maintenance slow and onboarding new clients costly.

What I Delivered

I took ownership of the project end to end.

  • Designed a three-stage daily pipeline that merges historical data from the legacy tool with data from the new platform
  • Built a cross-region transfer process to migrate millions of rows of historical ranking data
  • Validated and enhanced the calculated fields table - corrected calculation logic, added filter granularity, and rebuilt metrics to cascade to every reporting level
  • Moved calculation logic from Looker Studio into BigQuery - faster queries, fewer bugs, easier validation
  • Designed a cross-market aggregation method for unified reporting across all markets
  • Consolidated separate per-client codebases into one templated system, so new clients need only configuration changes
  • Wrote documentation and validation queries for ongoing monitoring

Technical Highlights

  • Three-stage daily schedule - extract 05:00 → merge 09:00 → calculate 11:00 UTC
  • Configuration-driven onboarding - new clients are added through configuration tables, not code changes
  • Safe to re-run - queries are idempotent, so re-running never creates duplicates
  • Multi-level hierarchy - metrics calculated at global, market and five keyword-group levels (L1–L5)
  • SEO metrics - visibility score, weighted visibility, search volume, ranking search volume, estimated clicks and position bucket distributions

Key Technologies

BigQuery, SQL, Scheduled Queries, Google Cloud Storage, Looker Studio, Git
